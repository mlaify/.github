## Projects

**[AttackMap](https://github.com/mlaify/AttackMap)** — *looking for help*\
Local-first defensive security analysis for codebases. Maps the attack surface,
traces request-to-sink data flow, and ranks evidence-anchored findings mapped to
MITRE ATT&CK. Your code never leaves your machine. Ships with a
[macOS app](https://github.com/mlaify/AttackMap-mac) and 15 analyzer plugins.

**[grrclone](https://github.com/mlaify/grrclone)**\
A free macOS menu bar app that mounts [rclone](https://rclone.org) remotes as
Finder volumes. No licence key, no telemetry, no kernel extension.
`brew install --cask mlaify/tap/grrclone`

## Principles

- **Privacy by default.** No telemetry, no phone-home, nothing collected that isn't needed.
- **Defensive only.** Output aims at remediation, never exploitation.
- **Status you can trust.** "Alpha" means alpha.
